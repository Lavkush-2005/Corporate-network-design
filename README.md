# Corporate Network Design using Cisco Packet Tracer

## Overview

This project demonstrates the design and implementation of a corporate network using Cisco Packet Tracer. The network is designed to provide secure, scalable, and efficient communication between different departments within an organization.

## Objectives

* Design a structured enterprise network.
* Implement routing and switching concepts.
* Enable communication between multiple departments.
* Improve network scalability and reliability.
* Apply networking best practices in a simulated corporate environment.

## Technologies Used

* Cisco Packet Tracer
* Cisco Routers
* Cisco Switches
* End Devices (PCs, Servers)
* TCP/IP Protocol Suite

## Features

* Designed a multi-department corporate LAN topology for HR, IT, and Finance teams using Cisco Packet Tracer.
* Configured Cisco 2911 Router with static IP addressing and activated network interfaces using CLI commands.
* Implemented VLAN segmentation (VLAN 10, 20, 30) on Cisco 2960 Switch for department-level network isolation and security.
* Deployed DHCP Server for centralized automatic IP address allocation across all departments.
* Applied multi-layer security by configuring console password, VTY remote access password, and enable secret password on Router.
* Verified end-to-end network connectivity through successful ping tests across all department PCs.

1. Download the `.pkt` file.
2. Open it in Cisco Packet Tracer.
3. Wait for the topology to load.
4. Review device configurations.
5. Test connectivity using the Ping command.
